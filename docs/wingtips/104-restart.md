# Hermes Wingtips #104: /restart

posted 2026-10-17. original: [https://x.com/witcheer/status/2111359054593544454](https://x.com/witcheer/status/2111359054593544454)

want to restart your Hermes Agent while you're away from your computer?

`/restart`

send it in the chat with your bot. it finishes the task it is working on, then restarts and messages you when it is back.

docs: [https://hermes-agent.nousresearch.com/docs/reference/slash-commands#messaging-slash-commands](https://hermes-agent.nousresearch.com/docs/reference/slash-commands#messaging-slash-commands)

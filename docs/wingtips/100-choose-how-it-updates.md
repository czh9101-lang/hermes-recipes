# Hermes Wingtips #100: choose how your Hermes Agent updates

posted 2026-10-13. original: [https://x.com/witcheer/status/2109909502187524193](https://x.com/witcheer/status/2109909502187524193)

a source install of Hermes Agent now goes from one published release to the next when you update.

want every commit on main instead?

`hermes update --set-channel main`

on a source install, Hermes Desktop has the same switch: Settings > About > Updates > Update channel.

docs: [https://hermes-agent.nousresearch.com/docs/getting-started/updating](https://hermes-agent.nousresearch.com/docs/getting-started/updating)

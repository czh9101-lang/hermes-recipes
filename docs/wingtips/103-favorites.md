# Hermes Wingtips #103: Favorites

posted 2026-10-16. original: [https://x.com/witcheer/status/2110996667893764440](https://x.com/witcheer/status/2110996667893764440)

switching between the same few models with your Hermes Agent?

click the star next to a model in the Hermes Desktop model picker

it moves into a Favorites section at the top, wherever you pick a model in the app.

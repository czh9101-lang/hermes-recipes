# Hermes Wingtips #101: Minimize to tray in Hermes Desktop

posted 2026-10-14. original: [https://x.com/witcheer/status/2110279446741839926](https://x.com/witcheer/status/2110279446741839926)

want your Hermes Agent to keep working after you close the window?

Settings > Appearance > Window layout > Minimize to tray

closing the main window then hides Hermes Desktop in the system tray, and your sessions keep running.

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/desktop#minimize-to-tray](https://hermes-agent.nousresearch.com/docs/user-guide/desktop#minimize-to-tray)

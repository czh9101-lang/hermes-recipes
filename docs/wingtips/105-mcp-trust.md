# Hermes Wingtips #105: trust: untrusted

posted 2026-10-18. original: [https://x.com/witcheer/status/2111721017336881281](https://x.com/witcheer/status/2111721017336881281)

want your Hermes Agent to ask before it changes anything through an MCP server?

`trust: untrusted`

add it under that server in config.yaml. tools the server marks read-only run as normal, and every other tool waits for your /approve.

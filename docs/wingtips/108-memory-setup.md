# Hermes Wingtips #108: hermes memory setup

posted 2026-10-22. original: [https://x.com/witcheer/status/2113170993082765672](https://x.com/witcheer/status/2113170993082765672)

Hermes Agent keeps its own memory in MEMORY.md and USER.md. a memory provider runs alongside it and adds things like semantic search, knowledge graphs and automatic fact extraction.

one command walks you through adding one:

`hermes memory setup`

pick a provider from the list, answer its setup questions and start a new session. your built-in memory stays on the whole time.

great for a long project, a research habit or an agent you talk to every day!

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/memory-providers](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory-providers)
